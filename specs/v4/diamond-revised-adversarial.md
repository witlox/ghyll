# Adversarial pass on consolidated artifact — 2026-05-25

## Summary

The revised artifact closes the majority of the 86 prior findings, but
introduces fresh structural problems the closure-map masks. The two
load-bearing regressions are (1) an import-cycle violation in
`runner/bindings_register.go` (the file imports `bootstrap` while
`bootstrap/init_attestations.go` already imports `runner` — Go will not
compile this), and (2) the `gates.ConceptsFS` snippet imports a package
path and asset file that do not exist in the working tree; the actual
embed lives at the repository root (`assets.go`, package `ghyll`).
Several closure-map cells also cite line numbers / method names that
diverge from the working tree (`Bus.Subscribers()` vs.
`SubscriberCount()`; `RemediationReport.Rounds` vs. `Reports`;
`session_engine.go:218` vs. `:215`; `NewRunner(tier, passes)` drops the
existing `*Registry` argument silently). A handful of revisions also
re-open prior findings — most notably, the ClauseID-namespacing fix
for H6 only applies to the auto-synthesis fallback branch and leaves
declared-ClauseID collisions intact, and the new step-3-before-bump
ordering trades H5's failure window for a different asymmetric
mid-drain state nobody named.
