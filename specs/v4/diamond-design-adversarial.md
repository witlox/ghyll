# Adversarial pass on architect design — 2026-05-25

## Summary

The design has one structural flaw that blocks the dispatcher wire as
written: `runDispatcherAdversarialPhase` is supposed to fire between
`OpenPass` and the verification loop, but the helper depends on
`FindingsStore` + `ClassificationsStore` + four hook callables — all of
which the dispatcher does not own and never has owned. The architect
adds them to `PassDispatcher` but never wires the runtime through, and
on top of that proposes a signature for the loop-bomb integration
(`harness.ProducerRemediate()(ctx, openFindings)`) whose actual return
type cannot satisfy `FixAttemptFn`'s `(madeProgress bool, err error)`
contract. Several other design changes invisibly require code edits
the architect did not flag (registry-key shape breaks every existing
clause in production grids; `Runner.Evaluate.snapshotDetails` would
have to strip the runner-stamped key BEFORE invocation, not after;
`engineRuntime.gridFile` referenced repeatedly does not exist).

## Adversarial verdict

The implementer **cannot proceed from this design without rework**.
The critical findings (C1–C7) include four wires that ship broken
(C1 loop-bomb signature, C2 missing Requirements, C3 missing
`gridFile` field, C4 stale on-disk grid read on amendment) plus
three structural mistakes that change semantics undocumented (C5
hand-list drift, C6 misdiagnosed snapshot concern, C7 close-reason
vocabulary). C2 + H4 together break the §11 spec the analyst quotes
by name: depth-classification doesn't fire on amendment-created
arrows and depth-sensitive clauses re-evaluate twice. The amendment
re-register flow (C4) is the most load-bearing flaw — the
architect's "re-registration is mandatory" rule is mechanically
unreachable.

The implementer-track should:

1. Re-spec the cycle's wire contract (C1, C2, H1, H4) with a single
   diagram showing what gets stamped where; the table of fields the
   helper passes to `RunRemediationLoop` is the contract.
2. Add `engineRuntime.gridFile *bootstrap.Grid` (C3) and decide
   whether `AmendmentCommitter` writes to disk (C4) or whether the
   in-memory `runner.Grid` is the binding source — this is an ADR.
3. Auto-derive `IsUniversalConcept` + `LanguageBoundConcepts` from
   the canonical YAMLs (C5, H9, M14).
4. Drop the `runner-stamped Args + blocklist` alternative for gap 4
   in favor of the `EvaluatorWithRunner` signature variant (C6).

Gap 2 is the cleanest section — its only critical (C4 cross-cuts
through gap 3) is borrowed from elsewhere; the rest is High or
Medium. The implementer can land gap 2 first and unblock gaps 1, 3,
4 with the redesign feedback in parallel.
